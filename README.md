# React Learning Project (Stepik)

This repository contains a learning project created while completing a **React course on Stepik**, focused on modern JavaScript and React fundamentals.  
The project was developed step by step as part of practical tasks, starting from core JavaScript concepts and moving to building a full React application.

During the course, I worked with **React components, JSX, props, state management, hooks (useState, useEffect, useMemo, useCallback), routing with react-router, and global state management using Redux Toolkit**. Both functional and class components were explored to understand React’s rendering process and lifecycle.

The project also covers common frontend practices such as list rendering, conditional rendering, component composition, styled components, and integration with third-party UI and chart libraries. This repository reflects my solid foundation in React and modern frontend development.
